# Session 1: Introduction to Statistics in Data Science

This folder contains the complete solutions for **Session 1 - Introduction to Statistics in Data Science** using an interactive Jupyter Notebook.

---

## 📓 Primary Assignment Notebook

👉 [**`session_01_intro_to_statistics.ipynb`**](session_01_intro_to_statistics.ipynb)

### Tasks Covered:
1. **Task 1: Daily App Actions & Data Classification:** 5 actions across Instagram, Zomato, and Flipkart categorized into Numerical vs. Categorical (Discrete, Continuous, Nominal, Ordinal) with full reasoning.
2. **Task 2: Music App Genre Classification:** Classifying `['Pop', 'Rock', 'Jazz', 'Hip-Hop', 'Pop', 'Rock', 'Jazz', 'Pop']` as Categorical (Nominal) data with 2–3 line justification and frequency plot.
3. **Task 3: Improving App Features with Statistics:** Analysis of Zomato's Star Rating & Delivery Estimation using Bayesian weighted shrinkage and 85th percentile estimates.
4. **Task 4: Spotify Playlist Recommendation Statistical Terms:** Explaining **Mode**, **Median**, and **Variance/Std Dev** with concrete one-line recommendation engine examples.
