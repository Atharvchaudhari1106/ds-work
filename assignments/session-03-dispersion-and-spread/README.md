# Session 3: Measures of Dispersion & Spread

This folder contains the complete solutions for **Session 3 - Measures of Dispersion & Spread** using an interactive Jupyter Notebook.

---

## 📓 Primary Assignment Notebook

👉 [**`session_03_measures_of_dispersion.ipynb`**](session_03_measures_of_dispersion.ipynb)

### Topics & Tasks Covered:
1. **Range & Interquartile Range (IQR):** Transaction amounts dataset, finding $Q_1$, $Q_2$, $Q_3$, and calculating $\text{IQR} = Q_3 - Q_1$.
2. **Variance & Standard Deviation:** Comparing Sample ($n-1$, Bessel's correction) vs. Population ($N$) formulas on student exam scores.
3. **Outlier Detection using Tukey's IQR Fences:** Calculating Lower Fence ($Q_1 - 1.5 \times \text{IQR}$) and Upper Fence ($Q_3 + 1.5 \times \text{IQR}$) with an annotated boxplot.
4. **Z-Score Standardization & Empirical Rule:** Normalizing delivery durations and categorizing observations within $\pm 1\sigma, \pm 2\sigma, \pm 3\sigma$.
5. **Real-World Dataset Dispersion:** Computing Range, Variance, Std Dev, and Coefficient of Variation (CV) on the IPL player statistics dataset.
