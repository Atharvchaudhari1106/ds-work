## 📓 Primary Assignment Notebook

👉 [**`session_04_skewness_basic.ipynb`**](session_04_skewness_basic.ipynb)

### Tasks Covered:
1. **Task 1: Swiggy Daily Orders (Right-Skewed):** Graphing `[12, 15, 17, 14, 13, 16, 200, 18, 14, 15]` and explaining why the 200-order outlier creates a long right tail with $\text{Mean} (33.40) > \text{Median} (15.00)$.
2. **Task 2: Instagram Influencer Followers Skewness:** Follower counts `[5, 7, 8, 8, 9, 10, 12, 15, 95]` (in thousands). Demonstrates that $\text{Mean} (18.78\text{k}) > \text{Median} (9.00\text{k})$, proving positive (right) skewness caused by the 95k mega-influencer outlier.
3. **Task 3: Real-World Example of Right-Skewed Data:** In-depth analysis of **Zomato Food Delivery Order Bill Amounts** with simulated lognormal distribution plot showing the compact lower cluster (₹150–₹450) and long upper tail (₹5,000–₹30,000+).
4. **Task 4: Flipkart Ratings (Left-Skewed):** Ratings `[3, 3, 4, 4, 4, 5, 5, 5, 5, 5]`. Frequency graph with one-line justification explaining negative (left) skewness where $\text{Mean} (4.30) < \text{Median} (4.50) < \text{Mode} (5.00)$.
