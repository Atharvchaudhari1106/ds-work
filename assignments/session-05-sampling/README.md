# Session 5: Sampling

This folder contains the complete solutions for **Session 5 - Sampling** using an interactive Jupyter Notebook.

---

## 📓 Primary Assignment Notebook

👉 [**`session_05_sampling.ipynb`**](session_05_sampling.ipynb)

### Tasks Covered:
1. **Task 1: Population vs. Sample Examples:** 3 real-world app examples (Instagram followers, Zomato restaurants, Flipkart catalog items) comparing population ($N$) and sample ($n$).
2. **Task 2: Simple Random Sampling in Python:** Simulating random sampling of 50 users from 1,000 user IDs using `random.sample()` without replacement.
3. **Task 3: Sampling Swiggy Food Delivery Times:** Explaining why sampling is used instead of querying all historical orders (computational efficiency, cloud costs, and operational timeliness).
4. **Task 4: Selection Bias in Spotify Survey:** Identifying and explaining Undercoverage/Selection Bias when a music preference survey is only sent to Bollywood listeners.
5. **Task 5: Sampling Techniques for BookMyShow:** Implementing Stratified Random Sampling (by metro vs. non-metro tiers) and Systematic Sampling (every $k$-th booking) with visual breakdown.
