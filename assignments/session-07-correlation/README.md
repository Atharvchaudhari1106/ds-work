# Session 7: Correlation

This folder contains the complete solutions for **Session 7 - Correlation** using an interactive Jupyter Notebook.

---

## 📓 Primary Assignment Notebook

👉 [**`session_07_correlation.ipynb`**](session_07_correlation.ipynb)

### Tasks Covered:
1. **Task 1: Instagram Hours vs. Posts Made:** 7-day scatter plot with regression trendline illustrating strong positive linear correlation ($r = +0.98$).
2. **Task 2: Zomato vs. Swiggy Orders Correlation:** Computing Pearson correlation matrix using `numpy.corrcoef()`, demonstrating that overall online food ordering appetite creates strong positive co-movement across both platforms ($r = +0.9859$).
3. **Task 3: Real-Life Variables Analysis:** Detailed paragraph exploring the strong negative correlation between recreational short-form video watch time (Reels/Shorts) and focused academic study hours.
4. **Task 4: Spotify Time vs. Test Marks (Negative Correlation):** 10-pair dataset showing near-perfect negative linear correlation ($r = -0.9968$), with an annotated scatter plot and downward-sloping regression line.
