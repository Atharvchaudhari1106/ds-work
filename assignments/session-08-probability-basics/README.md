# Session 8: Probability Basics

This folder contains the complete solutions for **Session 8 - Probability Basics** using an interactive Jupyter Notebook.

---

## 📓 Primary Assignment Notebook

👉 [**`session_08_probability_basics.ipynb`**](session_08_probability_basics.ipynb)

### Tasks Covered:
1. **Task 1: Basic Probability Function:** Custom `calculate_probability(event_count, total_outcomes)` function applied to finding the probability of getting Heads on a fair coin toss ($P = 0.50$).
2. **Task 2: Dice Rolling Simulation (100 Trials):** Simulating 100 six-sided dice rolls, tracking occurrences of face 6, and comparing experimental probability ($0.20$) against theoretical probability ($1/6 \approx 0.1667$) with a frequency chart.
3. **Task 3: Spotify Recent Songs Probability:** Array of 20 recent song genres, determining the probability of randomly picking a Pop song ($9/20 = 0.45$).
4. **Task 4: Zomato Food & Dessert Intersection Probability:** Function calculating the probability of ordering both food and dessert ($P(\text{Both}) = \frac{|\text{Food} \cap \text{Dessert}|}{|\text{Food} \cup \text{Dessert}|}$).
5. **Task 5: Conditional Probability for Recommendations:** Implementing Flipkart's *"Frequently Bought Together"* logic using $P(\text{Headphones} \mid \text{Phone}) = \frac{N(\text{Both})}{N(\text{Phone})}$ demonstrating a 2.5x recommendation lift.
